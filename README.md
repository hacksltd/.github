# .github

This repository renders a README – `./profile/README.md` – on the [github.com/hacksltd](https://github.com/hacksltd/) organization landing page.

This version of the README is shown to the general public (non-organization members). [An alternative README](https://github.com/hacksltd/.github-private) is shown to organization members who are logged in to GitHub.
